# DL1 redistributable authoring regression

The C# test tree contains a hermetic DL1-shaped authoring regression. Its
binary inputs are generated by test code and contain no retail Dying Light
assets.

Run it from the repository root:

```powershell
.\tools\validate_dl1_authoring_e2e.ps1 -Configuration Release
```

The regression proves one continuous production-code path for:

- RP6L zlib pack enumeration through two precedence-conflicting providers;
- physical `RetailAssetId` resolution, exact-identity reopen, and SQLite
  persistence of both provider candidates;
- type-272 hierarchy, triangle, skin-palette, material-slot, and morph-table
  decoding into `Dl1MeshData` and a retail-derived `RigDefinition`;
- content-SHA binding into the target rig and retarget-map fingerprint;
- generated body and mimic ANM2 export, parse, semantic decode, and domain
  import on one rational timeline;
- manual source-to-target retargeting and a non-destructive authored bone
  correction;
- authored versus preview-only bone and morph ownership, including a
  preview-only procedural stage and runtime morph threshold;
- body+mimic export through the authoritative evaluator and descriptor
  ordering;
- decoded-value checks after ANM2 re-import; and
- deterministic animation-library RP6L construction, atomic write, reopen,
  byte identity, and animation-script metadata parsing.

This regression is not evidence for retail-only behavior. The following gates
still require configured DL1 packs or captured Windows 1.55 evidence:

- coverage of every base/DLC type-272 layout, rig family, LOD, material, skin
  palette, and container classification;
- the generated fixture itself is not retail proof; separate read-only
  `player_1_tpp` and `armored` controls cover SHORT4 position-delta
  dequantization and renderer handoff, while facial visual/game validation
  remains open;
- retail shader, texture, helper, player FPP/TPP, and family-specific IK
  behavior;
- CPU/GPU visual goldens, device-loss and large-pack stress; and
- comparison against the locked in-game validation corpus.
