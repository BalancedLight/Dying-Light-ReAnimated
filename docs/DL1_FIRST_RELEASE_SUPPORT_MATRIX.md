# DL ReAnimated C# DL1 first-release support matrix

This is the explicit scope contract for the C# first-release candidate. It is
not a declaration that the candidate has passed every release gate. The
regression map remains authoritative for open validation work.

Status terms:

- **Supported**: implemented with deterministic C# regression coverage.
- **Profile limited**: implemented only for named, evidence-backed DL1 layouts
  or rigs; unsupported variants fail visibly.
- **Preview only**: never exported unless a separate authored layer owns it.
- **Reference fallback**: the Python/Blender oracle remains available during
  the refactor, but the workflow is not a native C# feature yet.
- **Deferred**: outside this DL1 first-release contract.
- **Validation open**: implemented, but required corpus, capture, hardware, or
  clean-machine evidence is not complete.

The checked-in historical-suite audit fixture classifies 616 collected nodes as
92 directly mapped, 317 deliberately excluded by this scope, and 207 still
pending. A **Supported** row below describes the implemented C# contract; it
does not erase pending behavioral-parity nodes. See
`DL1_PYTHON_SUITE_AUDIT.md`.

Non-deterministic rows and required target-bind decisions fail export preflight until explicitly reviewed, and saved maps remain bound to source/target signatures and the retail target fingerprint. |

| Bone editing | Supported | The selected immutable layer receives numeric and translate/rotate/local-scale gizmo TRS keys while preserving its existing keys and authored/preview-only scope. The selected bone track's mode is editable directly in WPF and remains unchanged when later numeric or gizmo keys are inserted. Cubic/Bezier interpolation is deferred because schema 1 has no tangent contract. Rotation supports local/global axes and preserves exact double-precision quaternion values when translation or scale changes; scale is finite, positive, and bounded to `0.001..1000`. A drag is pinned to its project, animation, rational frame, and destination layer and cancels if any destination changes. ## Fidelity badges

| Badge | Meaning |
| --- | --- |
| **Raw** | Exact decoded/authored data owned by the offline pipeline, with no runtime-emulation claim. |
| **DL1 profile** | Versioned selected DL1 corrections/projections. This is the highest built-in tier today. |
| **Game validated** | Both the Windows build fingerprint and validation-capture fingerprint must match independently trusted evidence. Project-provided capture metadata is not trusted by itself; no trusted capture registry ships yet, so built-in profiles visibly remain downgraded. No universal pixel-identical claim is made. |

The toolbar exposes Raw and DL1 profile as an explicit project-persisted
selection. That selection is stored separately from the versioned DL1 profile,
so temporarily inspecting Raw data does not discard a saved game-validation
fingerprint. Raw FPP can follow the exact evaluated `EyeCamera` row with the
ordinary scene lens, but it does not silently enable the DL1 hands projection,
safe-frame emulation, or procedural stages.

Physics, cloth, all animation-graph states, exact retail shaders and their
normal/specular/mask behavior, post-processing, runtime randomness, and speech
are outside every badge.
